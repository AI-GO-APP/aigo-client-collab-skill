# 固定比喻

跟客戶說話時，技術詞一律換成下表的白話。**同一件事整段對話用同一個比喻**，不要一下說「草稿」一下說「暫存」。
第一次出現時可以括號附原詞，之後只用白話。

## 基本詞

| 技術詞 | 跟客戶說 | 比喻（需要解釋時用） |
|---|---|---|
| repo（儲存庫） | 專案資料夾 | 一支 app 的「總檔案櫃」，所有版本都收在裡面 |
| commit | 存一個版本 | 像 Word 存檔，但每次存檔都留著，可以回到任何一次 |
| branch（分支） | 草稿副本 | 把正本影印一份來改，改好再放回正本；改壞了丟掉影本就好 |
| main | 正本 | 檔案櫃裡那份大家認的正式版本 |
| PR（Pull Request） | 收件單 | 「我改好了，請收進正本」的申請單，附上改了什麼 |
| merge（合併） | 收進正本 | 把影本的修改正式寫回正本 |
| issue（客戶這邊開給工程師） | 寫給工程師的單子（請協助、知會） | 給隊友的便條：想做什麼、查到什麼、想請他幫什麼 |
| issue（工程師開給客戶，研究任務） | 工程師發來的請求 | 工程師請你幫忙查、幫忙回答的一張單子 |
| PR 請審閱（reviewer） | 請工程師看一眼 | 送印前請同事幫忙校稿 |
| sync／compile／publish（AI GO 發布） | 上線（發布到正式網址） | 印正式版：先把稿子送印刷廠（同步）、排版校對（編譯）、再發給所有人（發布） |
| 草稿版（AI GO 未發布的 VFS） | 試印版 | 印刷廠的打樣，只有自己看得到，同事看不到 |
| 正式網址 | 大家在用的那個網址 | 已經發出去的正式版 |
| rollback（回復） | 退回上一版 | 把正式版換回上一次印的那一版 |
| 測試、型別檢查 | 自動檢查 | 送印前的校稿：錯字、漏頁、格式不對都會被抓出來 |
| 前端 | 畫面 | 你看到、會點的部分 |
| 後端、action | 背後的處理 | 櫃台後面的辦事員：你按「送出」後，他負責查資料、算數字、存檔 |
| 資料表 | 帳冊 | 一本格式固定的帳冊，每一列是一筆資料、每一欄是一個項目 |
| 欄位 | 帳冊的一欄 | 例：員工帳冊裡的「到職日」那一欄 |
| 預設表／自建表 | 平台內建的帳冊／我們自己做的帳冊 | 文具店買的標準帳冊，和我們自己設計格式的帳冊 |
| 權限、角色 | 門禁卡 | 每個人的門禁卡能開哪幾扇門；改權限就是改門禁設定 |
| 資料存取規則（data gate） | 門禁規則 | 「人資部的卡才能開薪資櫃」這種規則 |
| API | 窗口 | 系統之間辦事的窗口，照規定格式遞單子才會受理 |
| 金鑰、Token | 鑰匙／通行證 | 有了它就能進門辦事，所以不能給別人、不能貼出來 |
| Webhook | 自動通知 | 別的系統一有事就自動打電話過來 |
| 排程（cron） | 定時工作 | 像每天早上 9 點自動列印報表的鬧鐘 |
| bug | 問題、故障 | — |
| log（紀錄） | 系統日誌 | 系統自己寫的流水帳，出問題時翻它找原因 |
| 環境變數 | 系統設定值 | 寫在系統設定裡、不寫在程式裡的值（像鑰匙） |
| Custom App | 一般 app | 在 AI GO 平台上直接做、直接發布的 app |
| Hosted App | 容器 app | 自己帶整套機器進駐平台的 app，發布方式不一樣 |
| 實作計畫（Phase 1.5） | 做法摘要 | 動工前的施工圖：做什麼、放哪、誰能用、怎麼驗收 |
| 模板 | 範本 | 別人做好的類似系統，拿來當參考或起點 |
| access_mode（internal／external） | 內部用／給外部的人用 | 大門開在公司裡面還是街上，蓋好就不能移 |
| 寫入閘門 | 改真實資料前的四步 | 算筆數、先備份、試一筆、你說可以再全部改 |
| 外部服務、egress | 跟別的系統接線 | 平台幫你登記好要打電話過去的對象，沒登記的打不出去 |
| 成員邀請 | 邀請信 | 寄一封邀請信，對方點連結註冊後就能登入；48 小時後失效 |
| 平台問題回報（report_issue） | 回報給 AI GO 開發團隊 | 不是我們系統的問題，是平台本身的，請平台修 |
| E2E 測試、操作驗收 | 實際操作一次 | 照你描述的情境，從登入到看到結果實際點一遍 |

## 講原因時常用的比喻

- **少帶資料**：「像寄信漏寫郵遞區號，信寄得出去，但到不了」
- **快取／沒更新**：「像手上還拿著舊的影印本，正本已經改了」
- **權限不夠**：「門禁卡沒開這扇門，不是門壞了」
- **兩人同時改**：「兩個人同時改同一份正本，後存的會蓋掉先存的」
- **型別錯誤**：「表格的『日期』欄填了文字，校稿時會被退回」
- **逾時**：「辦事員處理太久，窗口先關了」

## 不要用的說法

- 不說「很簡單」「只要…就好」：對客戶不一定簡單。
- 不說「系統限制」就結束：講清楚是哪一種限制、有沒有別的做法。
- 不用英文縮寫當主詞（「VFS 衝突了」）：改說「線上的版本跟我們手上的不一樣」。
